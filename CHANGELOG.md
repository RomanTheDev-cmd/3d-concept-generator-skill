# История версий

## 1.1.1 — 2026-10-18 (Codex)
- Согласованы обновление карточки каждого кандидата, текущая версия, фактический родитель и отдельно утверждённая основа; определены откат по ветке и принятие именованного варианта.
- Убрано лишнее промежуточное утверждение для сразу запрошенной серии ракурсов; кандидат может быть явно выбранным исходником.
- Проверки учитывают режим фона, разрешённые элементы композиции и непрозрачность материала; неизвестные задние поверхности отделены от подтверждённых, стороны больше не переворачиваются механически.
- Палитра общая внутри цветовой версии; пользовательская перекраска не объединяется с палитрами прежних версий.
- Аудит/исправление инструкций не запускают новые генерации без явного запроса тестовых изображений.
- В стартовой подсказке плагина нейтральный фон уточнён как прозрачный по действующему умолчанию.

## 1.1.0 — 2026-10-18 (Codex)
- Основные среды — обычный ChatGPT Chat и Work из любого чата с подключённым плагином; без привязки к Mac, локальным путям и скриптам.
- Карточка замысла, версии/утверждённая основа и перенос через сообщения и вложения.
- Таблица точечных команд с сохраняемыми признаками; настоящий возврат прежней версии без перегенерации.
- Сверка ракурсов по 3–6 признакам, асимметрии и видимости поверхностей; пять реальных проверочных сценариев.
- Цвета задаёт пользователь; максимум 4, без самостоятельного сокращения палитры. Фон по умолчанию прозрачный PNG; белый — по запросу/требованию целевой программы.
- Иконка и её отображение проверяются отдельно от содержимого навыка; включённый файл не считается доказательством отображения.

## 1.0.1 — 2026-10-18 (Codex)
- По прямому указанию Романа введён обязательный максимум 4 базовых цвета на весь объект, включая мелкие детали; единая палитра при правках и между ракурсами.
- Белый, чёрный, серый и намеренно разные оттенки входят в лимит; фон и нейтральные светотени отдельно оговорены. Планирование палитры и визуальная проверка учитывают предел.

## 1.0.0 — 2026-10-18 (Codex)
- Первый выпуск по мастер-промпту Романа: самостоятельная генерация концепт-изображений, читаемая объёмная форма, чистые цвета, нейтральная подача, согласованные отдельные ракурсы и адресное редактирование.
- Нет зависимости от удалённого imageto3d; нет встроенного создания CAD/STL/3MF. Генерация выполняется доступным инструментом среды, без обещания одинаковых возможностей у Codex и Claude.
- Единый источник iCloud, ссылки обоих агентов; пакет плагина — снимок выпуска.
